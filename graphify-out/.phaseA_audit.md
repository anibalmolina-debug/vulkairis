## 5. Exact wiring gaps for Phase A (no code changed; proposed fixes are for the build phase)

1. **First-level relative includes anchor at display names, not pack paths (fail-loud, low severity).**
   Every runtime caller passes a shader *display name* as `includerPath`: `GlShaderMixin`
   intercepts with Iris's `GlShader` name (e.g. `gbuffers_terrain.vsh`-style / program name),
   and `validateGraphicsProgram`/`prewarmOne` pass `name + "_vert"` / `name + "_frag"`.
   `parentDir()` of a slash-less name is `""` (pack root), so a surviving *relative* `#include`
   at the first level resolves against the root instead of alongside the true pack file and
   becomes a named `#error` (miss), not a silent wrong-file hit. Absolute `/...` includes
   (the fix5 shape) are unaffected, and nested (level ≥ 1) relatives anchor correctly via
   `found.resolvedPath()`. Residual risk is narrow: Iris already expands quoted relatives
   before interception, leaving only angle-bracket/sodium-terrain first-level relatives in
   subdirectory files exposed. Candidate fix: thread the real shaders-relative path through
   interception (e.g. derive from `ProgramSource` name + stage extension) or fall back to
   trying the entry's own directory candidates before emitting the miss.
2. **No `runClient` evidence yet (acceptance item, §3.5).**
   Unit + fixture-zip gates pass; `fix5`-class `#include /program/*` errors going to zero on
   Complementary/BSL fixtures still needs a live-client run with a real pack (scenario matrix
   in plan §11). Nothing in the audit suggests it will fail — `packFiles()` snapshot,
   generation gating (`SourceProvenance`), and structured-miss behavior are all in place —
   but it is unverified by definition in a headless audit.
3. **Non-gaps explicitly confirmed (do not "fix"):** memo key including pack identity is
   stricter than the spec's `(generation, entry)` minimum — correct, keep. `IrisPackFiles`
   provider fallback serving Iris-expanded text is idempotent under re-expansion — keep.
   `follow` clamping the *includer* path (`clampSegments(from)`) while failing the *spec*
   on escape is the right asymmetry — keep.
